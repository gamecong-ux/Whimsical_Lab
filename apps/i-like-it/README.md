# I like it

気になった画像を「like」「use」「Objective」の三つの観点で -2.00〜2.00（0.01 刻み）で評価し、Google ドライブに保存する個人用 Web アプリ。画像はプロジェクトごとに分けて管理できる。
ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）。

## ファイル構成

Whimsical Lab モノレポの `apps/i-like-it/` に置いている。公開するのは `public/` の中身だけ。

| ファイル | 内容 |
|---|---|
| `public/index.html` | 入口 |
| `public/config.js` | アプリ名・Google クライアント ID・容量上限 |
| `public/store.js` | Google ログインと Google ドライブへの保存（デモ用のメモリ保存も含む） |
| `public/app.js` | 画面と操作（一覧、スライダー評価、絞り込み・並べ替え、削除、自動保存） |
| `public/styles.css` | 見た目（OS の設定に合わせてライト／ダーク） |
| `public/icon.svg` | アプリのアイコン（タブ・画面左上） |
| `public/privacy.html` | プライバシーポリシー（Google の同意画面からリンク） |
| `I like it を開く.vbs` | ダブルクリックで起動するためのファイル（`public/` を配信する。公開はしない） |
| `README.md` | この説明（公開しない） |

## 使い方（このパソコンで）

**`I like it を開く.vbs` をダブルクリック**すると、ブラウザーでアプリが開く。

- 開いた直後は**デモ**（画面上部に「デモ（保存されません）」）。画像の追加や評価を試せるが、保存はされず、ページを閉じると消える。
- 右上の **「ログイン」** で Google にログインすると、Google ドライブに保存されている記録に切り替わる。このときデモで追加したデータは捨てられる（データがある場合は確認が出る）。
- ログアウトするとデモに戻る。

- Google ログインはファイルを直接開いた状態（`file://`）では動かないため、このファイルが裏で小さなサーバー（Python の `http.server`）をウィンドウなしで起動し、`http://localhost:8080/` を開いている。
- サーバーはこのパソコンからしか接続できない（`127.0.0.1`）。一度起動すると、パソコンを再起動するまで裏で動き続ける（ほとんど負荷はない）。2 回目以降のダブルクリックはブラウザーを開くだけ。
- ポート 8080 を別のアプリが使っている場合や、Python が見つからない場合は、メッセージが出る。
- デスクトップから開きたい場合は、このファイルを右クリック →「ショートカットの作成」で作ったショートカットをデスクトップに置く。
- ポート番号を変えるときは、vbs 内の `PORT` と、Google Cloud の「承認済みの JavaScript 生成元」の両方を変える。

## 開発時の起動

```bash
python -m http.server 8080 --bind 127.0.0.1 --directory public
```

ブラウザーで `http://localhost:8080/` を開く（デモで始まる）。
`http://localhost:8080/?demo-fail` では、デモの保存がわざと時々失敗し、「保存失敗 → 再試行」の動きを確認できる。

## Google 連携の設定（本番利用に必要）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成する。
2. 「API とサービス」→「ライブラリ」で **Google Drive API** を有効にする。
3. 「OAuth 同意画面」（Google Auth Platform）を設定する。
   - ユーザーの種類：外部
   - スコープ：`openid`、`email`、`profile`、`.../auth/drive.appdata`
   - 公開ステータスは「本番環境」。使う権限は機密でない `drive.appdata` とプロフィール情報だけなので、Google の審査なしで誰でもログインできる。
   - 本番にするには「ブランディング」に、ホームページ `https://i-like-it-dul.pages.dev/`、プライバシーポリシー `https://i-like-it-dul.pages.dev/privacy.html`、承認済みドメイン `i-like-it-dul.pages.dev` を登録する。
   - **アプリのロゴはアップロードしない**（ロゴを入れると Google の審査が必要になる）。
4. 「認証情報」→「OAuth クライアント ID を作成」→ 種類「ウェブ アプリケーション」。
   - 承認済みの JavaScript 生成元に、アプリを開く URL のオリジンを登録する。
     - ローカル：`http://localhost:8080`
     - 公開先：例 `https://<ユーザー名>.github.io`
   - リダイレクト URI は不要。
5. 発行されたクライアント ID を `config.js` の `googleClientId` に貼り付ける。

## 企画書 13 章の仮決定事項

| 事項 | このバージョンでの扱い |
|---|---|
| アプリ名 | 「I like it」。`config.js` の `appName` で変更可（Google のログイン画面に出る名前は、Google Cloud の「ブランディング」で別に設定） |
| 設置先 | 静的ホスティング（上記）。サーバー側の処理は持たない |
| Google 連携 | Google Identity Services のトークン方式。要求する権限は `drive.appdata` とプロフィール情報のみ |
| ドライブ上の保存方式 | ドライブの**アプリ専用領域（appDataFolder）**に保存。利用者のほかのファイルは権限上読めず、操作もできない |
| 対応画像形式・容量 | JPEG / PNG / GIF / WebP / AVIF、1 枚 20MB まで（`config.js` で変更可） |

### アプリ専用領域の中身

- `records.json` … 全記録（プロジェクト一覧と、各画像のファイル名・所属プロジェクト・三つの評価・日時）
- `img-<id>.<拡張子>` … 元画像
- `thumb-<id>.webp` … 一覧表示用の縮小画像（長辺 800px）

アプリ専用領域はドライブの通常の画面には表示されない。容量の確認や全データの削除は、ドライブの「設定」→「アプリの管理」から行える。

## 動作の補足

- 評価項目：**like**（自分の好み）、**use**（自分の作品で使いたいか）、**Objective**（好みを離れた完成度・巧さ）。保存データ上の項目名は従来どおり `like` / `want` / `objective`。
- 評価は一覧画面だけで行う。画像にマウスを乗せると三つのスライダー（左が 2「いい」、右が -2「悪い」。1 行に「名前・バー・数字」）が開き、動かすだけで評価できる。0.01 刻みで動き、小数点第 2 位まで表示する。普段は点数の数字だけを表示する。
- 新しく追加した画像は三つとも 0.00（普通）から始まる（未評価の状態は持たない）。
- 記録するのは画像と三つの評価、登録日・更新日のみ（タイトル・メモ・タグ・出典は持たない）。
- 削除：画像にマウスを乗せると右上に出る × から。確認画面を挟む。
- プロジェクト：
  - 画像はすべてどれか 1 つのプロジェクトに入る（未分類はない）。プロジェクトがないときは、まず作成するよう案内が出る。
  - 画面上部のタブで「すべて」と各プロジェクトを切り替える。「＋ プロジェクト」で作成。
  - 「すべて」では、プロジェクト名の見出しの下に、そのプロジェクトの画像を並べる。見出しを押すとそのプロジェクトを開く。
  - プロジェクトを開いた状態で画像を追加すると、そのプロジェクトに入る。「すべて」で追加すると、入れるプロジェクトを選ぶ画面が出る（その場で新しく作ることもできる）。
  - 開いているプロジェクトのタブの「…」から、名前の変更と削除ができる。**削除すると中の画像と評価も Google ドライブから削除される**（確認あり、元に戻せない）。
  - 以前の版で追加した、どのプロジェクトにも入っていない画像は一覧に出ない。ログイン時に削除するかを確認する（「あとで」なら残して次回また確認）。
- 評価の変更は約 0.7 秒後に自動保存。
- 保存に失敗すると「保存失敗」と「再試行」ボタンが出る。評価は画面に残る。ログインの期限切れ（約 1 時間）が原因の場合は、再試行で再接続してから保存する。
- ログイン中、保存が終わっていない状態でタブを閉じようとすると、ブラウザーが確認する。
- 画像の追加：ボタン、ドラッグ＆ドロップ、Ctrl+V（コピーした画像の貼り付け）。
- 絞り込み：各評価の範囲（下限〜上限、空欄は制限なし）を指定。「1以上」「0以上」「-1以下」のボタンもある。項目どうしは「すべて」を満たすものを表示。
- 同時に複数のタブで編集すると、後から保存した内容で上書きされる（初期版の制約）。
- 以前の 1〜5 で保存したデータは、読み込み時に自動で -2〜2（5→2、3→0、1→-2）に変換される。
