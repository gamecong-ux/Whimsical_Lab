I like it

プライバシーポリシー

最終更新日：2026年11月17日

「I like it」（以下「本アプリ」）は、気になった画像を三つの観点で評価して保存する個人向けの Web アプリです。本アプリが利用者の情報をどのように扱うかを説明します。

1. 取得する情報

Google でログインしたとき、Google から次の情報を受け取ります。

  • Google アカウントのメールアドレス、名前、プロフィール画像（画面右上の表示に使います）
  • Google ドライブの「アプリ専用の保存領域」へのアクセス権（drive.appdata）

ログインせずにデモとして使う場合、情報は取得しません。デモで追加した画像は、ブラウザーの中だけで扱い、ページを閉じると消えます。

2. 情報の保存場所

本アプリで追加した画像、評価、プロジェクトは、利用者自身の Google ドライブにある本アプリ専用の保存領域に保存されます。本アプリの運営者のサーバーには保存しません（本アプリは画面のファイルを配信するだけで、データを受け取るサーバーを持ちません）。

本アプリは、この専用の保存領域以外の Google ドライブ上のファイルを読んだり、変更したり、削除したりすることはできません。

3. 利用目的

取得した情報は、本アプリの機能（画像と評価の保存・表示、ログイン中のアカウントの表示）のためだけに使います。広告や分析には使いません。

4. 第三者への提供

取得した情報を第三者に販売・提供することはありません。データは利用者のブラウザーと Google の間でのみやり取りされます。

本アプリによる Google API から受け取った情報の利用と他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

5. ブラウザーに保存する情報

次回のログインを簡単にするため、ログインしたメールアドレスをブラウザーの保存領域（localStorage）に記録します。ログアウトすると削除されます。

6. データの削除

  • 画像やプロジェクトは、本アプリの画面からいつでも削除できます。
  • 保存したデータをすべて削除するには、Google ドライブの「設定」→「アプリの管理」で本アプリを選び、「隠しアプリデータを削除」を実行してください。
  • 本アプリへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

7. お問い合わせ

本ポリシーや本アプリについてのお問い合わせは、GitHub の Issues からお願いします。

8. 改定

本ポリシーを変更する場合は、このページで公開します。
