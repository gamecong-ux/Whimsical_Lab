# Whimsical Lab

Webアプリと今後の作品を紹介するHubです。`dev/hub` では、画面左側で見切れる円盤から作品を選び、プリズムを通った光が右側の詳細へ広がるデザインを開発しています。現在は公開済みアプリ1件と仮の項目6件を掲載しています。

## 確認

`dist/index.html` をブラウザで開くと確認できます。ビルドやインストールは不要です。

## アプリを登録

`dist/apps.js` の `works` を編集します。`name` は作品名（漢字）、`nameEn` は英語の作品名（見出しの横に小さく表示。作品名は「漢字＋英語名」の形にそろえる）、`description` は短い説明、`url` は公開済み作品の URL、`symbol` は円盤上の記号、`image` は光のスクリーンの上に、すりガラス状にぼかした半透明の白枠・角丸・斜めの RGB ずれ（`index.html` の `#rgb-shift`、動きなし）付きの写真。画像部分にはノイズをかけず、余白（白枠）にだけはっきりしたノイズと、縁の赤・青の RGB ずれ（box-shadow）を重ねるとして置く作品の画面画像（`dist/previews/` に置く。空なら光だけ。押すとアプリへ移動。ふだんはぼやけて歪みながら揺れる光の残像（歪みは `index.html` の `#photo-warp`）で、カーソルを合わせると歪みが消えて実体化し、くっきり見える。ホバーできない端末では最初から実体化した表示）、`color` は光と仮画像の色です。URL が空の場合は準備中となり、移動ボタンは表示されません。画像評価帳には実際の画面（`previews/i-like-it.png`）を設定済みです。

画面のどこでもマウスホイールやトラックパッドで円盤を回せます（縦・横どちらのスクロールでも可）。回している間にスクロール量が一定（333px）に届くと、その場で次の作品へなめらかに送ります（1刻み133pxのマウスで3刻み、100pxなら4刻み）。届くまでは円盤が少しだけ傾いて手応えを返し、届かずに止めると約0.7秒後に元の作品へゆっくり戻ります。止めた後に勝手に次へ進むことはありません。1回の操作（手を止めて揃うまで）で動くのは前後1作品までで、大きく回しても2個先へは進みません。円盤のドラッグでも回せ、離すと最寄りの作品へ揃います。揃う動き（スナップ）は、止まった位置から距離に応じて0.7〜1.6秒かけ、ゆっくり加速・減速して動きます。円盤上のアイコンをタップ（クリック）すると、その作品まで最短の向きになめらかに回ります。キーボードの矢印キーも使えます。

光線は円盤の選択位置からプリズムの左面に当たり、右面から分かれた光が右側の「光のスクリーン」になります。スクリーンは `dist/screen.webp`（1637×961、透過。遠近のついた台形・球体・端のぼかしを含む）で、分光はスクリーンの左端の高さにぴったり広がってつながります。作品の説明と「アプリを開く」は、このスクリーンを下地に暗い文字で表示します。作品名の見出しはスクリーンの外に常に表示します。位置は画面サイズに合わせて `apps.js` で計算し、SVG で描いています。分光の色は虹色に、選択中の作品の `color` を混ぜています。円盤が回っている間（ドラッグ・ホイール・スナップ中）は、スクリーン上の内容 → スクリーン → 分光・光線の順にすばやく消えます。止まると、光線が円盤からプリズムへ伸び（〜0.2秒）、届いた瞬間に分光とスクリーンが表示され、内容が現れます（0.85〜1.15秒）。ページを開いたときも同じ順番で現れます。表示中のスクリーンは、SVG フィルター（`index.html` の `#screen-wobble`）でゆっくり歪み、わずかに膨らんだり傾いたりしてゆらぎます（回転中と「動きを減らす」設定のときは止まります）。

## 画面の大きさ

PC・タブレット（幅701px以上）では、画面全体を横1920×縦880の固定レイアウトで組み、ウィンドウの横幅いっぱいに拡大縮小します。余った上下は背景と同じ色の帯になります（縮尺は `apps.js` の `fitCanvas`）。ウィンドウが極端に横長（21:9 など）のときは、上下に最低限の帯（高さの7%ずつ）を残すため、左右にも帯が出ます。スマホ幅（700px以下）では縦並びのレイアウトになります。

## 円盤のアイコン

各作品のアイコンは円盤の縁の外側に並び、縁の上には位置の目印となる小さな点があります。選択中のアイコンは、円盤が回り終えて中心で止まってから縁の上（光線の出発点）に移り、光ります。回転中はすべてのアイコンが縁の外にあります。

## 背景

背景はマットブラックに固定しています。円盤には `dist/disc.webp`（1254px 四方、円の直径は約1031px、周囲は透明な発光）、プリズムには `dist/prism.png` を使っています。分光はSVGで描画しています。文字とアイコン以外（背景・円盤・プリズム・光・スクリーン）には、軽いぼかしとフィルムのようなノイズ（`.stage-grain`）をかけています。デザインの参照イメージは `../docs/hub-concepts/` にあります。

## Cloudflare Pagesへの公開

GitHub連携で公開しています。`main` に送信すると、自動で再公開されます。

| 設定 | 値 |
| --- | --- |
| プロジェクト名 | `whimsical-lab`（URL：`https://whimsical-lab-8oa.pages.dev`） |
| プロダクションブランチ | `main` |
| フレームワークプリセット | なし |
| ビルドコマンド | 空欄 |
| ルートディレクトリ | `hub` |
| ビルド出力ディレクトリ | `dist` |
| ビルド監視パス（含める） | `hub/*` |

公開されるのは `hub/dist` の中身だけです。`SPEC.md` や `drafts/` は公開されません。
Hubは静的ファイルだけで動作します。各アプリのホスティングや利用料は、それぞれの公開先によります。独自ドメインの取得費用は別途必要です。
