# Whimsical Lab

Webアプリと今後の作品を紹介するHubです。`dev/hub` では、画面左側で見切れる円盤から作品を選び、プリズムを通った光が右側の詳細へ広がるデザインを開発しています。現在は公開済みアプリ1件と仮の項目6件を掲載しています。

## 確認

`dist/index.html` をブラウザで開くと確認できます。ビルドやインストールは不要です。

## アプリを登録

`dist/apps.js` の `works` を編集します。`name` は作品名、`description` は短い説明、`url` は公開済み作品の URL、`symbol` は円盤上の記号、`color` は光と仮画像の色です。URL が空の場合は準備中となり、移動ボタンは表示されません。詳細の画像は現在すべて仮のビジュアルです。

画面のどこでもマウスホイールやトラックパッドで円盤を回せます（縦・横どちらのスクロールでも可）。回している間にスクロール量が一定（333px）に届くと、その場で次の作品へなめらかに送ります（1刻み133pxのマウスで3刻み、100pxなら4刻み）。届くまでは円盤が少しだけ傾いて手応えを返し、届かずに止めると約0.7秒後に元の作品へゆっくり戻ります。止めた後に勝手に次へ進むことはありません。1回の操作（手を止めて揃うまで）で動くのは前後1作品までで、大きく回しても2個先へは進みません。円盤のドラッグでも回せ、離すと最寄りの作品へ揃います。揃う動き（スナップ）は、止まった位置から距離に応じて0.7〜1.6秒かけ、ゆっくり加速・減速して動きます。円盤上のアイコンをタップ（クリック）すると、その作品まで最短の向きになめらかに回ります。キーボードの矢印キーも使えます。

光線は円盤の選択位置からプリズムの左面に当たり、右面から分かれた光が右側の「光のスクリーン」になります。スクリーンは `dist/screen.webp`（936×550、透過。遠近のついた台形・球体・ぼかしを含む）で、分光はスクリーンの左端の高さにぴったり広がってつながります。作品の説明と「アプリを開く」は、このスクリーンを下地に暗い文字で表示します。作品名の見出しはスクリーンの外に常に表示します。位置は画面サイズに合わせて `apps.js` で計算し、SVG で描いています。分光の色は虹色に、選択中の作品の `color` を混ぜています。円盤が回っている間（ドラッグ・ホイール・スナップ中）は、スクリーン上の内容 → スクリーン → 分光・光線の順にすばやく消えます。止まると、光線と分光が左から右へ伸び（〜0.5秒）、スクリーンが広がり（〜0.9秒）、内容が現れます（〜1.15秒）。ページを開いたときも同じ順番で現れます。

## 背景

背景はマットブラックに固定しています。円盤には `dist/disc.webp`（1254px 四方、円の直径は約1031px、周囲は透明な発光）、プリズムには `dist/prism.png` を使っています。分光はSVGで描画しています。デザインの参照イメージは `../docs/hub-concepts/` にあります。

## Cloudflare Pagesへの公開

GitHub連携で公開しています。`main` に送信すると、自動で再公開されます。

| 設定 | 値 |
| --- | --- |
| プロジェクト名 | `whimsical-lab`（URL：`https://whimsical-lab-8oa.pages.dev`） |
| プロダクションブランチ | `main` |
| フレームワークプリセット | なし |
| ビルドコマンド | 空欄 |
| ルートディレクトリ | `hub` |
| ビルド出力ディレクトリ | `dist` |
| ビルド監視パス（含める） | `hub/*` |

公開されるのは `hub/dist` の中身だけです。`SPEC.md` や `drafts/` は公開されません。
Hubは静的ファイルだけで動作します。各アプリのホスティングや利用料は、それぞれの公開先によります。独自ドメインの取得費用は別途必要です。
