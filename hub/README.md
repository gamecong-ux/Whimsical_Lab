# Whimsical Lab

Webアプリと今後の作品を紹介するHubです。`dev/hub` では、画面左側で見切れる円盤から作品を選び、プリズムを通った光が右側の詳細へ広がるデザインを開発しています。現在は公開済みアプリ1件と仮の項目6件を掲載しています。

## 確認

`dist/index.html` をブラウザで開くと確認できます。ビルドやインストールは不要です。

## アプリを登録

`dist/apps.js` の `works` を編集します。`name` は作品名、`description` は短い説明、`url` は公開済み作品の URL、`symbol` は円盤上の記号、`color` は光と仮画像の色です。URL が空の場合は準備中となり、移動ボタンは表示されません。詳細の画像は現在すべて仮のビジュアルです。

画面のどこでもマウスホイールを動かすと、その量に合わせて円盤がなめらかに回ります。マウスホイールとトラックパッドは、どちらもスクロール量（1000px で1作品）に合わせて連続して回ります。止めた位置が半作品分を超えていれば次へ、超えていなければ元の作品へ揃います（1刻み100pxのマウスで6刻み、133pxなら4刻み）。トラックパッドは縦・横どちらのスクロールでも回せます。円盤のドラッグでも回せます。操作を止めると、すぐ（約0.16秒後）最寄りの作品へ素早く揃います。キーボードの矢印キーや、記号の直接選択も使えます。

光線は円盤の選択位置からプリズムの左面に当たり、右面から分かれた光が詳細のプレビューへ広がります。位置は画面サイズに合わせて `apps.js` で計算し、SVG で描いています。分光の色は虹色に、選択中の作品の `color` を混ぜています。

## 背景

背景はマットブラックに固定しています。円盤・ぼかした光・仮画像はCSSで描画し、プリズムには `dist/prism.png` を使っています。デザインの参照イメージは `../docs/hub-concepts/` にあります。

## Cloudflare Pagesへの公開

GitHub連携で公開しています。`main` に送信すると、自動で再公開されます。

| 設定 | 値 |
| --- | --- |
| プロジェクト名 | `whimsical-lab`（URL：`https://whimsical-lab-8oa.pages.dev`） |
| プロダクションブランチ | `main` |
| フレームワークプリセット | なし |
| ビルドコマンド | 空欄 |
| ルートディレクトリ | `hub` |
| ビルド出力ディレクトリ | `dist` |
| ビルド監視パス（含める） | `hub/*` |

公開されるのは `hub/dist` の中身だけです。`SPEC.md` や `drafts/` は公開されません。
Hubは静的ファイルだけで動作します。各アプリのホスティングや利用料は、それぞれの公開先によります。独自ドメインの取得費用は別途必要です。
