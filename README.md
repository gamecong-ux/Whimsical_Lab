# Whimsical Lab

Whimsical Lab の Hub と各アプリをまとめたリポジトリ（モノレポ）です。
フォルダごとに別の Cloudflare Pages / Workers プロジェクトとして公開します。

| フォルダ | 内容 | 公開先 | Cloudflare の設定 |
| --- | --- | --- | --- |
| `hub/` | アプリ一覧（Hub） | `whimsical-lab-8oa.pages.dev`（独自ドメイン取得後は `<DOMAIN>`） | Pages：ルートディレクトリ `hub`、ビルド出力 `dist` |
| `auth/` | 共通ログイン（予定） | `auth.<DOMAIN>` | Workers |
| `apps/<アプリ名>/` | 各アプリ（予定） | `<サブドメイン>.<DOMAIN>` | Pages：ルートディレクトリ `apps/<アプリ名>` |
| `docs/` | 複数フォルダにまたがる作業指示 | 公開しない | — |

## ルール

- アプリごとにフォルダを分け、ほかのフォルダのファイルを直接読み込まない。共通化したいものは相談してから決める。
- 各 Pages プロジェクトには「ビルド監視パス」を設定し、自分のフォルダが変わったときだけ再公開されるようにする。
  - 例：Hub は `hub/*`
- 秘密情報（クライアントシークレットや署名鍵）はリポジトリに入れない。リポジトリは公開されている。
- 各フォルダの詳細は、そのフォルダの README.md を参照する。
