# Hubデザイン再構成案

参考画像4点と、選択したアプリからプリズムに光が入り、拡散した光が詳細を投影するという構想をもとに作成した比較用イメージ。画面画像、説明文、アプリ名以外のUIは仮表現であり、実装済みの仕様ではない。

| 案 | イメージ | 特徴 |
| --- | --- | --- |
| A: Prism Editorial | `prism-editorial.png` | 左に小さな選択円盤、中央にプリズム、右に明るい大きな投影画面。参考画像1の余白と柔らかい球体を強く取り込む。 |
| B: Luminous Disc | `luminous-disc.png` | 画面外に切れる発光円盤をダイヤルとして使い、右に柔らかい投影を置く。参考画像4の円形の質感に近い。 |
| C: Type and Spectrum | `type-spectrum.png` | 画面外の細い円形ダイヤル、中心のプリズム、大きな文字と画面画像を明確に分ける。黒の余白が多く、参考画像2・3のグラフィック要素を取り込む。 |

共通して検討する点：ダイヤルは画面の一部に収める、詳細画面を主役にする、光はアイコン→プリズム→投影の順に見せる。色は選択アプリごとに変えるとしても、背景と操作部分は黒を基調とする。

## 採用案：B — Luminous Disc

2026年11月16日、B案をデザインの基準に選択。参照画像は `luminous-disc.png`。この画像は構図と光の方向性を示すもので、画面内の架空のUI・文言をそのまま実装しない。

- 黒い余白を主役にし、画面左側で一部が見切れる柔らかい発光円盤をダイヤルにする。
- 円盤の周囲にアプリマークを配置し、選択中のものだけを明るくする。円盤は画面の約3割以内に抑える。
- 選択したマークから細い白い光線をプリズムへ通し、拡散した光を右側の大きな詳細画面に投影する。光は背景にとどめ、文字とボタンの読みやすさを優先する。
- 詳細はアプリ名、実際の画面画像、短い説明、移動ボタンを基本とする。比較画像にある装飾用の架空テキストは採用しない。
- マウス・タッチ・キーボードでアプリを選択できるようにする。自動回転は行わない。
- スマホでは円盤の一部を画面端に収め、詳細を縦に配置する。光の経路は残しつつ、横幅が狭い場合は拡散光を短く弱くする。
- 将来、自己紹介などアプリ以外の項目も同じ選択機構に追加できるようにする。

`dev/hub` の `hub/dist` に初版を実装。円盤は下に配置し、詳細の画像はユーザーの指定に従い仮のビジュアルを使用する。今後、実際の画面画像と各項目の説明文が揃ったら差し替える。
